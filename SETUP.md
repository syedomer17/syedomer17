# V3 — Professional profile

This version deliberately drops the fake-terminal/AI-dashboard aesthetic.

Design:
- minimal editorial layout
- restrained GitHub-style palette
- no gradients
- no ASCII art
- no badge wall
- no unnecessary animation
- live public GitHub metrics
- automatic dark/light theme

Copy this folder into `syedomer17/syedomer17`, commit, and push.

Then run:
Actions → Refresh profile metrics → Run workflow

If the workflow cannot push:
Settings → Actions → General → Workflow permissions → Read and write permissions.
